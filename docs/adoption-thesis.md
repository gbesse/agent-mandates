# Adoption thesis

This document separates the intended commercial advantage from the capabilities already implemented.

First audience: Teams letting agents invoke tools with meaningful cost or side effects.

Potential accumulating asset: A mandate contract adopted across gateways, human approvals and tool adapters.

The README is the source of truth for the current alpha. Early publication alone does not make a market position defensible. Existing users, repeat usage and valuable integrations would be needed to establish the thesis. Open formats should make adoption easier; artificial data lock-in is not the objective.

## Next validation milestones

1. Ship a concrete transactional persistence adapter and durable execution outbox.
2. Integrate one real tool gateway with trusted cost calculation and authenticated approvals.
3. Obtain external security review and collect integration feedback before production claims.
