# agent-mandates v0.1.0 — public alpha

First usable release of the SDK and CLI, with fictional offline demos, optional Jev adapters, public TypeScript declarations and a Node.js 22/24 test workflow.

See the README for the implemented workflow and integration boundaries. Jev responses are mocked in this release's tests; no live model quality or production-readiness claim is made. The package is installable from this GitHub tag and is not published to npm.

MIT licensed. Depends on the pinned public DecisionPacks revision for Jev response validation, deadlines and decision records. No build or deployment step is required.
